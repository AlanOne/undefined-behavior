If you just installed [Omarchy](https://omarchy.org) and aren't sure where to go next, read
these in this order:

1. **[Omarchy Setup Guide]({{< relref "posts/omarchy-setup-guide" >}})** — the handful of things worth
   changing in your first hour, before you build habits around the defaults.
2. **[Hyprland Keybindings Cheat Sheet]({{< relref "posts/hyprland-keybindings-cheat-sheet" >}})** — print
   this or keep it in a tab until the binds are muscle memory.
3. **[Turn an Old Laptop Into a Home Server]({{< relref "posts/old-laptop-to-home-server" >}})** — once your
   desktop feels good, this is the natural next project.
4. **[Best Self-Hosted Apps for a Home Server]({{< relref "posts/self-hosted-apps-home-server" >}})** — what
   to actually put on that server once it's up.

More guides get added as they're tested for real, not written speculatively — check the
[posts index]({{< relref "posts" >}}) for everything published so far.

## Want it pre-packaged instead of typed by hand?

The touchpad tuning, window rules, and extra keybindings covered across these guides are
also available as a ready-to-run installer — the
[Omarchy Power Pack](https://alanjancic.gumroad.com/l/omarchy-power-pack). It backs up your
`~/.config/hypr` before touching anything and lets you apply each module individually, plus
it includes the full 224-bind keybinding reference offline. Entirely optional — everything
in it is also just written out in the guides above for free if you'd rather type it yourself.
